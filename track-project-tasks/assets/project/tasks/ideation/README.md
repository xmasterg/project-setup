# Feature ideation and planning

Use this folder for durable major-feature brainstorming, planning, decisions, and corrections. Humans and AI may create documents here.

- Prefer `YYYY-MM-DD-short-feature-name.md`.
- Start from `feature-plan.template.md` when useful.
- Keep context, goals, non-goals, constraints, decisions, open questions, and corrections current.
- Tasks derived from a document must list its exact project-relative path in `planning_docs`.
- Read every linked document before implementing or revising related tasks.
